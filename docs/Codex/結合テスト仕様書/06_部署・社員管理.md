# 06 部署・社員管理 結合テスト仕様書

## 1. テスト目的

会社管理者が自社の部署と社員を個別画面・CSVの両方から正しく管理でき、他社データの混入、登録途中のデータ残り、意図しないパスワード変更を防げることを確認します。

## 2. 事前条件

- A-MANAGER、B-MANAGERでログインできる
- A社に営業部・管理部、B社に営業部を準備する
- A社にA-EMPLOYEE1、B社にB-EMPLOYEE1を準備する
- 未使用の社員番号、ログインID、メールアドレスを用意する
- CSVはUTF-8版とShift_JIS版を用意する

## 6. 重点確認と不具合判定

- CSV取込は全行を1単位として扱います。途中行が不正なのに一部だけ登録・更新された場合は重大な不具合です。
- 現行実装ではCSVのパスワード長検査が画面登録と一致しない可能性があります。IT-CSV-11で短いパスワードが登録できた場合は不具合として記録します。
- IT-EMP-13では「削除表示でも履歴保護のため利用停止になる」という違いを、画面表示とDBの両方で確認します。
