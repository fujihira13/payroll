# 02 権限・データ分離 結合テスト仕様書

## 1. テスト目的

3権限が許可された画面だけを使用し、社員管理者は自社データだけ、一般社員は公開済み本人明細だけを参照・更新できることを確認します。

## 2. 事前条件

- A社・B社と各社の社員管理者・一般社員が存在
- A社・B社に部署、社員、メールテンプレート、自社明細設定、給与処理、給与明細が存在
- 公開済みと未公開の給与明細を各1件以上準備
- 直接URLへ指定する各データの内部IDを確認済み

## 3. テストケース

| ID | 区分 | 事前条件 | 操作・入力 | 期待結果 | 種別 |
|---|---|---|---|---|---|
| IT-ACL-01 | 未認証 | 未ログイン | `/manage/companies`へ直接アクセス | `/login/manage`へ移動 | 自動 |

## 4. 確認するDB状態

権限外操作の前後で対象データの更新日時・内容・件数が変わっていないことを確認します。画面が403・404でもDBが更新されていればFAILです。
