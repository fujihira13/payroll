# 09 給与処理・CSV取込 結合テスト仕様書

## 1. テスト目的

会社管理者が対象年月と明細設定を指定して給与処理を作成し、CSVから社員ごとの金額を一括登録できることを確認します。特に、金額・社員・列の誤りがあるときに一部だけ反映されないこと、取込時点の内容が明細へ保存されることを重視します。

## 2. 事前条件

- A-MANAGER、B-MANAGERでログインできる
- A社に有効な自社明細設定を1件準備する
- A-EMPLOYEE1、A-EMPLOYEE2、B-EMPLOYEE1を準備する
- A社社員番号と「基本給」「残業手当」「所得税」等を含む標準CSVを準備する
- 下書き、公開待ち、公開済みの給与処理を各1件準備する
- DB確認前に対象年月、社員数、期待合計を計算して実施記録へ記載する

## 5. 合計の計算確認

各社員について、次を電卓または表計算で別途計算して照合します。

- 支給合計 = 支給カテゴリの数値項目の合計
- 控除合計 = 控除カテゴリの数値項目の合計
- 差引支給額 = 支給合計 - 控除合計
- 給与処理全体の合計 = 対象社員全員の各合計

表示が合っていてもDB値が異なる、またはDB値が合っていてもPDFだけ異なる場合は不具合です。

## 6. 重点確認と不具合判定

- CSV取込は全行を1単位として扱います。1行でもエラーなら、それ以前の正常行も含めてDB更新0件であることを確認します。
- 現行実装では同一CSV内の重複社員が最後の行で上書きされ、処理件数だけ行数になる可能性があります。IT-PAY-20で件数や結果が不整合なら不具合として記録します。
- 現行実装では利用停止社員をCSV対象から除外しない可能性があります。IT-PAY-21は実結果を記録し、公開前の業務判断対象にします。
