# 給与明細ポータル 結合テスト仕様書

## 1. 目的

この資料は、給与明細ポータルを構成する画面、認証、データベース、CSV、メール、定期実行、PDFが、機能の境界を越えて正しく連携することを確認するための結合テスト仕様書です。

単一の入力欄や内部関数だけではなく、利用者の操作から結果が画面・データベース・メール・ファイルへ反映されるところまでを確認します。

## 2. 対象範囲

| 区分 | 対象 |
|---|---|
| 利用者 | システム管理者、社員管理者（permission 9）、一般社員（permission 1） |
| Web | ログイン、管理画面、社員画面、入力検査、権限制御 |
| データ | 企業、管理者、部署、社員、帳票、明細設定、給与処理、給与明細、閲覧記録 |
| ファイル | 社員CSV、給与CSV、給与明細PDF |
| 外部連携 | SMTP／Mailpit、Scheduler |
| 運用確認 | Dockerサービス、ヘルスチェック、ログ |

給与計算そのもの、勤怠システム連携、銀行振込、年末調整、監査ログ、多要素認証、本番バックアップは対象外です。

## 4. テストケースの読み方

各ケースは次の列で構成します。

| 列 | 意味 |
|---|---|
| ID | テストケースを一意に識別する番号 |
| 区分 | 正常、異常、権限、境界、状態、回帰などの観点 |
| 事前条件 | 操作前に必要なログイン状態やデータ |
| 操作・入力 | テスターが行う具体的な手順 |
| 期待結果 | 画面、DB、メール、ファイルで成立すべき結果 |
| 種別 | 手動、自動、または両方 |

## 5. 合否判定

| 判定 | 使用条件 |
|---|---|
| PASS | 期待結果をすべて満たした |
| FAIL | 期待結果と1つでも異なった |
| BLOCKED | 環境障害や前提データ不足で実施できなかった |
| NOT RUN | 未実施 |
| N/A | 仕様変更等により対象外と承認された |

FAIL時は、実際の結果、再現手順、画面画像、ログ、使用データ、発生日時を残します。「現行実装上の注意」として記載されたケースでも、期待結果と異なれば自動的にPASSにはせず、不具合または仕様確認として記録します。

## 6. 推奨実施順

```text
共通環境確認
  → 1. 認証・アカウント
  → 2. 権限・データ分離
  → 4. 企業・システム管理者管理
  → 5. ベース帳票管理
  → 6. 部署・社員管理
  → 7. メール管理
  → 8. 自社明細設定
  → 9. 給与処理・CSV取込
  → 10. 承認・予約公開・通知
  → 11. 給与明細閲覧・PDF・閲覧状況
  → 3. ダッシュボード集計の最終確認
```

ダッシュボードは途中でも確認できますが、件数を確実に検証するため、業務データ作成後の最終確認を推奨します。

## 7. 横断結合シナリオ

### 7.1 初期導入

```text
初期システム管理者作成
  → システム管理者ログイン
  → 企業と初期社員管理者を登録
  → 仮パスワードを伝達
  → 社員管理者ログイン
  → 初回パスワード変更
  → 自社ダッシュボード表示
```

### 7.2 給与明細配布

```text
ベース帳票作成
  → 自社明細設定作成
  → 部署・社員登録
  → 給与処理下書き
  → 給与CSV取込
  → 社員別明細確認
  → 承認・公開予約
  → Scheduler公開・通知
  → 社員が詳細・PDFを閲覧
  → 社員管理者が閲覧状況確認
```

### 7.3 情報分離

A社・B社を用意し、3権限で一覧、直接URL、登録・更新・削除、本人明細を確認します。他社・他人の情報が画面、エラー、DB更新結果から漏れないことを確認します。

## 8. 証跡の最低要件

各ケースで必要に応じて次を保存します。

- 操作前後の画面画像
- 入力に使ったCSV
- ダウンロードしたCSV・PDF
- Mailpitの受信メール画像またはエクスポート
- DB確認結果
- アプリ・Scheduler・メールのログ
- 自動テストの実行結果

ファイル名は`テストID_実施日_内容`を推奨します。例：`IT-AUTH-05_20260828_5回失敗後.png`。

## 9. 現行自動テスト

2026年8月28日時点では20テスト・77アサーションです。自動テストは結合テストの一部を補助しますが、画面表示、Mailpit、ブラウザダウンロード、複数ブラウザ、運用ログなどは手動確認が必要です。

実行コマンド：

```text
docker compose exec app php artisan test
```
