# 給与明細ポータル 機能別処理概要

## 1. この資料について

このフォルダーには、現在の実装コードを基準に、給与明細ポータルの全機能を利用者の権限別に整理した資料を格納しています。

コードを読めない方でも、次の内容が分かることを目的としています。

- 誰が使える機能なのか
- 画面で何を入力・操作するのか
- 操作後にシステム内部で何が起きるのか
- 成功時と失敗時にどう分かれるのか
- どのデータが参照・更新されるのか
- 他社・他人のデータをどのように保護しているのか
- 現時点での制限や注意点は何か

## 2. 3つの権限

| 権限 | 保存場所・判定 | 主な役割 |
|---|---|---|
| システム管理者 | 専用の`admins`情報と`admin`認証 | 企業、システム管理者、全社共通のベース帳票を管理します。 |
| 社員管理者 | 社員情報の`permission=9` | 自社の部署、社員、明細設定、給与処理、メールを管理します。自分の給与明細も閲覧できます。 |
| 一般社員 | 社員情報の`permission=1` | 公開済みの自分の給与明細を閲覧し、PDFを出力します。 |

社員管理者と一般社員は同じ`/login`を使用し、ログイン後にパーミッション値で管理機能の使用可否が決まります。

## 4. 給与明細が届くまでの順序

```text
システム管理者が企業を登録
  → 初期社員管理者を同時作成
  → システム管理者がベース帳票を作成
  → 社員管理者が部署と社員を登録
  → 社員管理者が自社用の明細設定を作成
  → 社員管理者が給与処理の下書きを作成
  → 給与CSVを取り込む
  → 社員別明細を確認して公開予約
  → 自動処理が予約日時に公開・メール通知
  → 一般社員が明細を閲覧・PDF出力
  → 社員管理者が閲覧状況を確認
```

## 5. 資料を読むときの注意

- この資料は、将来の理想仕様ではなく、2026年8月28日時点の実装動作を説明しています。
- 画面の説明とコードの動作が食い違う場合は、コードで実際に行われる処理を優先して記載しています。
- 問題になり得る実装や未実装事項は、各資料の「現時点での注意事項」に明記しています。
- `404`は「対象が見つからない」、`403`は「ログインしているが権限がない」、`422`は「入力内容や現在の状態では処理できない」という意味です。
