# ベース帳票削除 — 処理概要

## 1. 目的

今後使用しないベース帳票を削除する機能です。ただし企業が一度でもその帳票から自社設定を作成している場合は削除しません。

## 2. 処理の流れ

```text
一覧で削除を押す
  ↓
ブラウザの確認ダイアログ
  ↓
対象帳票に会社設定が存在するか確認
  ├─ 存在する：削除せず、無効化を案内
  └─ 存在しない：帳票を削除
                      ↓
                  帳票項目も連動して削除
```

## 3. 使用中判定

会社設定が利用中か停止中かにかかわらず、対象ベース帳票にひも付く会社設定が1件でも存在すれば削除不可です。

画面には「会社で使用中のため削除できません。無効にしてください。」と表示します。削除の代わりに編集画面で「企業へ提供する」を外します。

## 4. 削除成功時

ベース帳票本体を削除すると、データベースの連動設定により原本項目も削除されます。会社設定が存在しないことを先に確認しているため、会社の運用中データは対象になりません。

## 5. 注意事項

- 削除は論理削除ではなく物理削除です。画面から復元できません。
- 会社設定自体を削除する画面機能がないため、一度会社にコピーされた原本は原則として削除できず、提供停止で管理します。
- 削除操作の専用監査ログはありません。

## 6. 動作確認の観点

1. 未使用帳票を削除できること。
2. 使用中帳票が削除されず、エラーが表示されること。
3. 未使用帳票削除時に原本項目も残らないこと。
4. 提供停止した帳票が企業側の新規選択に出ないこと。
