# システム管理者パスワード変更 — 処理概要

## 1. 目的

システム管理者が自分の現在のパスワードを確認し、新しいパスワードへ変更する機能です。別の管理者が仮パスワードを再発行した後の強制変更にも使用します。

| 項目 | 内容 |
|---|---|
| 対象 | システム管理者本人 |
| URL | `/manage/password` |
| 前提 | システム管理者としてログイン済み |

## 2. 入力条件

| 入力 | 条件 |
|---|---|
| 現在のパスワード | 必須。システム管理者専用の保存済みパスワードと一致すること |
| 新しいパスワード | 必須。8文字以上、英字と数字を含むこと |
| 確認 | 必須。新しいパスワードと一致すること |

## 3. 処理の流れ

1. 現在のパスワードを`admin`認証で照合します。
2. 新しいパスワードの長さ、英字、数字、確認欄を検査します。
3. 条件を満たしたパスワードを安全な保存形式に変換して更新します。
4. 初回パスワード変更の必要状態を解除します。
5. ログイン失敗回数を0に戻します。
6. ロック状態を解除します。
7. 企業一覧へ移動し、完了メッセージを表示します。

途中でエラーになった場合は何も更新しません。

## 4. 強制変更

システム管理者の新規登録またはパスワード再発行では、12文字の仮パスワードが発行され、初回変更が必要な状態になります。

この状態で企業一覧などを開こうとすると、共通の確認処理がパスワード変更画面へ戻します。変更完了後に通常のシステム管理機能を使えます。

## 5. 更新データ

| データ | 更新内容 |
|---|---|
| password | 新しいパスワードの安全な変換結果 |
| force_password_change | `false`（変更済み） |
| try_count | 0 |
| lock_status | `false`（解除） |

## 6. 注意事項

- 現在と同じパスワードを再登録することは禁止されていません。
- パスワード履歴、有効期限、多要素認証はありません。
- 他端末の既存ログインを一括終了する処理はありません。
- 本人が現在のパスワードを忘れた場合は、別のシステム管理者による再発行が必要です。

## 7. 動作確認の観点

1. 仮パスワード状態では企業一覧から変更画面へ移動すること。
2. 正しい現在パスワードで変更できること。
3. 英字または数字を含まない新パスワードが拒否されること。
4. 確認欄不一致で保存されないこと。
5. 成功後に企業一覧へ移動し、初回変更状態が解除されること。
