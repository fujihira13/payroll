# 管理者パスワード再発行・ロック解除 — 処理概要

## 1. 目的

ログインできなくなった別のシステム管理者に仮パスワードを発行したり、パスワードは変えずにロックだけ解除したりする機能です。

## 2. パスワード再発行

一覧の「パスワードリセット」を押すと、確認画面を挟まず次を実行します。

1. 記号なし12文字の仮パスワードを生成します。
2. 対象管理者のパスワードを仮パスワードへ変更します。
3. 初回パスワード変更を必要にします。
4. ロックを解除します。
5. 失敗回数を0に戻します。
6. 利用停止中の場合も利用中へ戻します。
7. 仮パスワードを画面に1回だけ表示します。

対象者は仮パスワードでログイン後、通常の管理画面へ入る前に自分のパスワードを変更します。

## 3. ロック解除

ロック中の管理者には「ロック解除」ボタンを表示します。実行すると次だけを更新します。

- ロック状態を解除
- 失敗回数を0

パスワード、利用可否、初回変更状態は変えません。現在のパスワードを本人が覚えている場合に使用します。

## 4. 2つの操作の違い

| 項目 | パスワード再発行 | ロック解除 |
|---|:---:|:---:|
| パスワード変更 | する | しない |
| 仮パスワード表示 | する | しない |
| 初回変更を必要にする | する | 変更しない |
| ロック解除 | する | する |
| 失敗回数0 | する | する |
| 利用中へ戻す | する | 変更しない |

## 5. 安全上の注意

- 仮パスワードは画面を離れると再表示できません。
- 仮パスワードはメールで自動送信されません。操作者が安全な別経路で伝える必要があります。
- パスワード再発行ボタンにはブラウザの確認ダイアログがありません。押すと直ちに旧パスワードが使えなくなります。
- 操作履歴を残す専用監査ログはありません。
- 自分自身に対しても再発行操作は可能です。その場合、現在のログインセッションは即時終了されませんが、次回の通常画面アクセスでは初回変更確認が働きます。

## 6. 動作確認の観点

1. 再発行後に旧パスワードでログインできないこと。
2. 仮パスワードでログインすると変更画面へ移動すること。
3. 再発行で利用停止とロックが解除されること。
4. ロック解除だけではパスワードが変わらないこと。
5. 仮パスワードが1回だけ表示されること。

- `resources/views/system/administrators/index.blade.php`
