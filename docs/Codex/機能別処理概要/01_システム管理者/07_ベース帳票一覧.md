# ベース帳票一覧 — 処理概要

## 1. 目的

全企業が自社用の給与明細設定を作る際に選べる「原本」を一覧で管理する機能です。ベース帳票は実際の社員明細ではなく、レイアウトと項目のひな型です。

## 2. 一覧表示

`/manage/templates`に、新しい帳票から15件ずつ表示します。

| 表示項目 | 内容 |
|---|---|
| 帳票名 | 原本の名称 |
| レイアウト | 標準給与明細または月額明細 |
| 項目数 | 原本に登録された項目件数 |
| 説明 | 先頭50文字程度 |
| 状態 | 企業へ提供中または停止中 |

各行から編集または削除を実行できます。検索機能はありません。

## 3. 企業側との関係

社員管理者がベース帳票を選ぶと、その時点の項目が自社用設定へコピーされます。

```text
ベース帳票（原本）
  ↓ 作成時にコピー
A社の明細設定    B社の明細設定
```

コピー後は別データです。ベース帳票を編集しても、すでに作成済みの会社設定や過去明細は変わりません。

停止中のベース帳票はシステム管理者一覧には残りますが、社員管理者が新しい自社設定を作る際の選択肢には表示されません。

## 4. データ参照

一覧取得時に、各帳票にひも付く項目数を同時に数えます。項目を1件ずつ別々に検索せず、一覧表示用の件数として取得します。

## 5. 注意事項

- 帳票名の重複は禁止されていません。
- 提供停止と削除は別です。会社で使用中なら削除できませんが、停止は編集画面から可能です。
- 作成者名は一覧に表示しません。
- 削除済み帳票の復元機能はありません。

## 6. 動作確認の観点

1. 15件単位で表示されること。
2. 項目数と提供状態が正しいこと。
3. 停止中帳票が企業側の新規選択肢に出ないこと。
4. 原本編集が既存会社設定へ反映されないこと。

## 7. 主な根拠ファイル

- `app/Http/Controllers/System/PayslipTemplateController.php`
- `resources/views/system/templates/index.blade.php`
- `app/Models/PayslipTemplate.php`
- `app/Http/Controllers/Company/PayslipSettingController.php`
