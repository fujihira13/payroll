# 初期システム管理者作成 — 処理概要

## 1. 目的

まだシステム管理者が1人もいない初期状態で、最初のシステム管理者をコマンドから作成する機能です。ログイン前に行うため、Web画面ではなくサーバー上の操作として実行します。

## 2. 実行コマンド

```text
php artisan payroll:create-system-admin
```

Docker環境では通常、アプリのコンテナ内でこのコマンドを実行します。

ログインID、氏名、パスワードをコマンドの引数・選択肢で渡すこともできますが、何も指定しなければ順番に入力を求められます。パスワード入力中は画面に文字を表示しません。

## 3. 入力条件

| 項目 | 条件 |
|---|---|
| 氏名 | 必須、文字列、255文字以内 |
| ログインID | 必須、半角英数字・ダッシュ・アンダースコア、4～20文字、既存と重複不可 |
| パスワード | 必須、8文字以上 |

Webのパスワード変更とは異なり、この初期作成コマンドでは英字と数字を両方含む条件までは検査していません。

## 4. 処理の流れ

```text
コマンド実行
  ↓
氏名・ログインID・パスワードを受け取る
  ↓
入力条件を確認
  ├─ エラー：最初のエラーを表示して失敗終了
  └─ 正常：パスワードを安全な形式に変換してadminsへ保存
              ↓
          作成完了を表示して正常終了
```

## 5. 作成される状態

| データ | 初期値 |
|---|---|
| 氏名・ログインID | 入力値 |
| パスワード | 安全な変換後の値 |
| 初回パスワード変更 | 不要 |
| 利用可否 | 利用中 |
| ロック | 解除 |
| 失敗回数 | 0 |

このコマンドで作った管理者は、すぐに`/login/manage`からログインできます。

## 6. 画面からの管理者登録との違い

| 比較 | 初期作成コマンド | 管理者画面から登録 |
|---|---|---|
| 使用場面 | 管理者がまだいないとき | 既存管理者が追加するとき |
| パスワード | 操作者が入力 | 12文字を自動生成 |
| 初回変更 | 不要 | 必要 |
| 実行場所 | サーバーのコマンド | Web画面 |

## 7. 注意事項

- コマンドに`--password`でパスワードを直接書くと、端末履歴や実行中プロセスから見える可能性があります。対話入力の利用が安全です。
- 最初の管理者だけに限定する件数チェックはありません。条件を満たせば2人目以降もコマンドから作成できます。
- 作成操作を記録する専用監査ログはありません。

## 8. 主な根拠ファイル

- `app/Console/Commands/CreateSystemAdmin.php`
- `app/Models/Admin.php`
- `docs/deliverables/OPERATIONS_GUIDE.md`
