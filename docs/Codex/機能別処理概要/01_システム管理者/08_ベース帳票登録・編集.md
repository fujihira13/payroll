# ベース帳票登録・編集 — 処理概要

## 1. 目的

企業へ提供する給与明細のレイアウトと、支給・控除・勤怠などの共通項目を定義する機能です。

## 2. 帳票の入力項目

| 項目 | 条件 |
|---|---|
| 帳票名 | 必須、255文字以内 |
| レイアウト | 必須。標準またはコンパクト |
| 説明 | 任意、1000文字以内 |
| 企業へ提供する | 必須の真偽値 |
| 帳票項目 | 1件以上必要 |

レイアウトごとのスロット数は次のとおりです。

| レイアウト | 左列 | 右列 |
|---|---:|---:|
| 標準 | 12 | 12 |
| コンパクト | 8 | 8 |

## 3. 項目の入力内容

| 項目 | 説明・条件 |
|---|---|
| 項目コード | 必須、英数字・ダッシュ・アンダースコア、60文字以内、同じ帳票内で重複不可。会社側CSVの列名の原型 |
| 表示名 | 必須、255文字以内 |
| 分類 | 支給、控除、勤怠・その他 |
| 種類 | 金額、数値、文字 |
| 初期スロット | レイアウト内の左右位置、または未割当 |
| 必須 | 会社側の給与CSVで空欄を許可するかの初期値 |

画面では項目を追加・削除できます。表示順がそのまま保存順になります。

## 4. 新規登録処理

1. 帳票と全項目を検査します。
2. データベース処理を開始します。
3. ログイン中のシステム管理者を作成者として帳票を保存します。
4. 項目を画面順に0からの並び番号で保存します。
5. すべて成功した場合だけ確定します。

初期画面には「基本給」と「健康保険」の例が入っていますが、保存前に変更・削除できます。

## 5. 編集処理

編集時も全項目を検査した後、次の方式で保存します。

1. 帳票本体を更新します。
2. 既存の原本項目をすべて削除します。
3. 画面から送られた項目を新しい並び順で作り直します。

この処理もトランザクション内で行うため、途中失敗で項目が空になることを防ぎます。

会社設定側のコピーは更新しないため、完了メッセージにも「既存の会社設定には影響しません」と表示します。原本項目への参照は削除時に空になりますが、会社側にコピー済みのコード・表示名等は残ります。

## 6. 分類と金額計算への影響

後で会社側にコピーされ、給与CSVを取り込むときに次の計算へ使われます。

```text
総支給額 = 種類が金額 かつ 分類が支給 の合計
控除合計 = 種類が金額 かつ 分類が控除 の合計
差引支給額 = 総支給額 - 控除合計
```

「数値」や「文字」、または「勤怠・その他」は合計金額へ加えません。

## 7. 注意事項

- スロットの重複は禁止されていません。複数項目に同じスロットを設定できます。
- 未割当項目が混在していても保存できます。明細表示では1件でもスロット付き項目があるとスロット方式になり、未割当項目が画面やPDFに表示されない可能性があります。
- 編集は項目を作り直すため、原本項目の内部IDが変わります。
- 帳票名の重複、項目数の上限、金額の符号ルールはありません。

## 8. 動作確認の観点

1. 1項目以上で登録できること。
2. 同一帳票内の項目コード重複が拒否されること。
3. レイアウトに存在しないスロットが拒否されること。
4. 項目順と必須指定が保存されること。
5. 編集後も既存会社設定の内容が変わらないこと。
