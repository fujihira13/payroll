# 一般社員ダッシュボード — 処理概要

## 1. 目的

一般社員がログイン後、自分に公開された給与明細の件数、未閲覧件数、現在の所属部署を確認する画面です。

| 項目 | 内容 |
|---|---|
| 対象 | permission 1の一般社員 |
| URL | `/dashboard` |
| 前提 | ログイン済み、初回パスワード変更済み |

## 2. 表示内容

| 指標 | 数え方・表示 |
|---|---|
| 公開済み明細 | 本人の明細のうち、給与処理が公開済みの件数 |
| 未閲覧 | 本人の公開済み明細のうち、初回閲覧日時が空の件数 |
| 所属 | 現在の部署名。部署未設定なら「未設定」 |

## 3. 処理の流れ

1. ログイン中社員を取得します。
2. permissionが社員管理者ではないため、本人向け集計を選択します。
3. `employee_id`が本人と一致し、給与処理が公開済みの明細を数えます。
4. 同じ条件で未閲覧の明細を数えます。
5. 現在の所属部署名を取得します。
6. 3つのカードを表示します。

## 4. データへの影響

ダッシュボードを見るだけでは閲覧済みにならず、閲覧回数も増えません。明細詳細またはPDFを開いたときに初めて更新します。

## 5. 注意事項

- 公開待ち・下書きの明細は件数に含めず、存在も表示しません。
- 所属部署は現在の社員情報を表示し、給与対象月当時の部署履歴ではありません。
- 指標カードから明細一覧へ直接移動するリンクはありません。左メニューの「明細を見る」を使います。
- 社員管理者には同じURLで別の集計を表示します。

## 6. 動作確認の観点

1. 本人の公開済み明細だけ数えること。
2. 他人の明細が件数に含まれないこと。
3. 未公開明細が表示されないこと。
4. ダッシュボード表示で閲覧回数が増えないこと。

## 7. 主な根拠ファイル

- `app/Http/Controllers/DashboardController.php`
- `resources/views/dashboard.blade.php`
- `app/Models/Payslip.php`
