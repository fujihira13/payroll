# 給与明細PDF出力 — 処理概要

## 1. 目的

本人の公開済み給与明細をA4サイズのPDFファイルとして生成し、端末へダウンロードする機能です。

| 項目 | 内容 |
|---|---|
| 対象 | 一般社員、社員管理者本人 |
| URL | `/employee/payslips/{明細}/pdf` |
| ファイル名 | `payslip-YYYY-MM.pdf` |

## 2. 本人・公開確認

画面詳細と同じく、本人の明細であり給与処理が公開済みであることを確認します。不一致は`404`です。

URLを直接指定しても、他人や公開前のPDFは生成できません。

## 3. 閲覧記録

PDF出力も閲覧として扱います。生成前に初回閲覧日時、最終閲覧日時、閲覧回数を更新します。

一覧からPDFへ直接アクセスした場合も閲覧済みになります。詳細画面を開いてからPDFを押した場合は、詳細で1回、PDFで1回の合計2回です。

## 4. PDF生成処理

1. 明細、給与処理、会社、社員、部署を読み込みます。
2. mPDFの一時ファイル用フォルダーを準備します。
3. 日本語モード、A4、日本語フォントを設定します。
4. PDF専用HTMLを作ります。
5. mPDFでPDFデータへ変換します。
6. `application/pdf`としてダウンロード応答を返します。

PDF生成にはIPAゴシックフォントを指定し、日本語文字化けを防ぎます。

## 5. PDF内容

- 会社コード・会社名
- 対象月
- 社員名・社員番号
- 明細項目
- 総支給額・控除合計・差引支給額
- 公開日時

表示方法は画面詳細と同様で、スロットありなら左右列、なければ分類別です。

## 6. HTTP応答

| ヘッダー | 内容 |
|---|---|
| Content-Type | `application/pdf` |
| Content-Disposition | attachment。ブラウザにダウンロードとして扱わせる |

PDFをサーバー上の恒久ファイルとして保存せず、その都度メモリ上で生成して返します。一時処理用フォルダーは使用します。

## 7. 注意事項

- PDF生成に失敗しても、その前に閲覧回数が増えている可能性があります。
- 同じ対象月に複数明細がある場合でもファイル名は同じになるため、端末側で上書きや連番になる可能性があります。
- 一時フォルダーの書込権限や日本語フォント不足で生成に失敗します。
- スロット未割当項目が混在する場合の表示上の注意は画面詳細と同じです。
- PDFの改ざん防止署名やパスワード保護はありません。

## 8. 動作確認の観点

1. HTTP 200かつPDF形式で返ること。
2. 日本語が文字化けしないこと。
3. 他人・未公開明細を出力できないこと。
4. PDF出力で閲覧回数が増えること。
5. 標準・コンパクト相当の項目数でA4レイアウトを確認すること。
