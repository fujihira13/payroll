# 給与明細詳細・閲覧記録 — 処理概要

## 1. 目的

本人が公開済み給与明細の各項目と合計金額を画面で確認する機能です。詳細を開いた事実を閲覧情報として記録します。

## 2. 開く前の確認

URLで指定された明細について、次を両方確認します。

| 条件 | 理由 |
|---|---|
| 明細の社員IDがログイン本人と一致 | 他人の給与情報を見せないため |
| 給与処理が公開済み | 公開前の給与情報を見せないため |

どちらかが不一致なら`404`です。明細の存在や公開前であることを第三者に分かりにくくします。

## 3. 閲覧記録

確認に成功すると、画面表示前に次を更新します。

| データ | 更新方法 |
|---|---|
| 初回閲覧日時 | 空の場合だけ現在日時を入れる。2回目以降は維持 |
| 最終閲覧日時 | 毎回現在日時へ更新 |
| 閲覧回数 | 毎回1増やす |

## 4. 表示内容

### 会社・社員情報

- 会社コード、会社名
- 対象月
- 社員名、社員番号
- 現在の所属部署
- 公開日時

### 明細項目

取込時に保存した表示名、分類、種類、スロット、値を表示します。

1件でもスロットが設定された項目がある場合は、左列・右列に分け、スロットコード順で表示します。スロットが1件もない場合は、支給、控除、勤怠・その他の分類ごとに表示します。

金額項目には円記号と桁区切りを付け、数値・文字項目はそのまま表示します。

### 合計

- 総支給額
- 控除合計
- 差引支給額

合計は画面表示時に再計算せず、CSV取込時に保存した値を使います。

## 5. 過去明細の保全

項目情報はCSV取込時に明細内へコピーされています。自社設定の項目名や分類を後から変更しても、取込済み明細の内容は変わりません。

ただし会社名、社員名、社員番号、部署名は現在の関連情報から表示するため、後から変更すると過去明細の表示も現在値になる部分があります。

## 6. 注意事項

- スロット付き項目が1件でもあるとスロット表示になります。未割当項目はこの表示分岐では出力されない可能性があります。
- 同じスロットに複数項目がある場合はどちらも表示されます。
- 詳細画面を再読み込みするたび閲覧回数が増えます。
- 画面を開いたことは記録しますが、内容を読んだ時間や確認同意は記録しません。

## 7. 動作確認の観点

1. 他人の明細と未公開明細が`404`になること。
2. 初回表示で閲覧日時と回数1が記録されること。
3. 再表示で初回日時が変わらず回数が増えること。
4. スロットあり・なしの両レイアウトが表示できること。
5. 取込後の設定変更で項目内容が変わらないこと。
