# 社員管理者ダッシュボード — 処理概要

## 1. 目的

社員管理者がログイン後、自社の社員数、公開待ちの給与処理、公開済みだが未閲覧の明細数をまとめて確認する画面です。

| 項目 | 内容 |
|---|---|
| 対象 | permission 9の社員管理者 |
| URL | `/dashboard` |
| 前提 | ログイン済み、初回パスワード変更済み |

## 2. 表示する3つの指標

| 指標 | 数え方 |
|---|---|
| 社員 | 自社に所属し、削除されていない社員アカウントの件数 |
| 公開待ち | 自社の給与処理のうち状態が「承認済み・公開待ち」の件数 |
| 未閲覧明細 | 自社の公開済み給与処理に含まれ、初回閲覧日時が空の明細件数 |

社員数には一般社員と社員管理者の両方が含まれます。利用停止中でも削除されていなければ件数に含まれます。

## 3. 処理の流れ

1. ログイン中の社員情報を取得します。
2. permission 9かを判定します。
3. ログイン中社員の`company_id`を条件に社員数を数えます。
4. 同じ会社の公開待ち給与処理を数えます。
5. 同じ会社の公開済み明細から未閲覧件数を数えます。
6. 3つのカードと給与公開の手順を表示します。

画面下には「CSVを取り込む → 内容を確認・承認 → 予約日時に通知」という作業順も表示します。

## 4. 一般社員との表示切替

URLは一般社員と同じですが、`canManageCompany()`の結果で表示内容を切り替えます。permission 9なら自社管理指標、permission 1なら本人向け指標です。

## 5. データへの影響

表示専用のため、社員・給与・閲覧情報を更新しません。

## 6. 注意事項

- 社員数は利用中だけではなく利用停止中も含みます。
- 未閲覧数は公開済みだけが対象です。公開待ちの明細は含みません。
- 件数から各一覧へ直接移動するリンクはありません。
- 集計時点の情報を表示するため、他の操作後は再読み込みが必要です。

## 7. 主な根拠ファイル

- `app/Http/Controllers/DashboardController.php`
- `resources/views/dashboard.blade.php`
- `app/Models/User.php`
