# 部署一覧・登録・編集・削除 — 処理概要

## 1. 目的

社員を所属させる自社の部署を管理する機能です。他社の部署は表示・変更できません。

## 2. 一覧

`/company/departments`に部署コード順で15件ずつ表示します。

| 表示項目 | 内容 |
|---|---|
| 部署コード | 会社内で部署を識別するコード |
| 部署名 | 通常の名称 |
| 部署名カナ | 任意の読み仮名 |
| 所属人数 | 削除されていない所属社員数 |

部署検索機能はありません。

## 3. 登録・編集の入力条件

| 項目 | 条件 |
|---|---|
| 部署コード | 必須、英数字・ダッシュ・アンダースコア、30文字以内、自社内で重複不可 |
| 部署名 | 必須、255文字以内 |
| 部署名カナ | 任意、255文字以内 |

登録時の会社番号は画面入力を信用せず、ログイン中社員管理者の`company_id`を自動設定します。

## 4. 編集時の会社確認

URLで指定された部署の`company_id`と、ログイン中の会社番号を比較します。他社部署なら`404`として処理を止めます。

部署コードの重複確認も自社内だけで行うため、別会社が同じ部署コードを使うことは可能です。

## 5. 削除

削除前に所属社員が存在するかを確認します。

| 状態 | 結果 |
|---|---|
| 所属社員あり | 削除せず「所属社員がいるため削除できません」と表示 |
| 所属社員なし | 部署を論理削除し、一覧から除外 |

所属社員を別部署へ変更するか未設定にしてから削除します。

## 6. データへの影響

| 操作 | 更新内容 |
|---|---|
| 登録 | 自社の会社番号を付けて部署を追加 |
| 編集 | コード、名称、カナを更新 |
| 削除 | 削除日時を設定する論理削除 |

## 7. 注意事項

- 削除済み部署の一覧・復元機能はありません。
- 所属人数には利用停止中社員も含みます。
- 部署名カナは文字種を検査しないため、カタカナ以外も保存できます。
- 給与明細には社員の現在の部署関連を表示するため、社員の部署変更後に過去明細を開くと現在の部署名が表示されます。

## 8. 動作確認の観点

1. 同じ部署コードを自社内で重複登録できないこと。
2. 別会社では同じコードを使用できること。
3. 他社部署の編集・削除が`404`になること。
4. 所属社員がいる部署を削除できないこと。
5. 削除後に一覧から消えること。
