# 給与処理一覧・下書き作成 — 処理概要

## 1. 目的

月ごとの給与明細配布単位を作り、下書き・公開待ち・公開済みの状態と、社員の閲覧状況を管理する機能です。この資料では一覧と最初の下書き作成を説明します。

## 2. 一覧

`/company/payroll`に自社の給与処理を対象月の新しい順で15件ずつ表示します。

| 表示 | 内容 |
|---|---|
| 対象月・名称 | 給与処理の基本情報 |
| 状態 | 下書き、承認済み・公開待ち、公開済み |
| 明細数 | 取り込まれた社員別明細数 |
| 閲覧済み | 初回閲覧日時がある明細数／全明細数 |
| 公開日時 | 公開済みなら実公開日時、未公開なら予約日時 |

検索、編集、削除機能はありません。

## 3. 状態

```text
下書き
  ↓ CSV取込・内容確認・承認
承認済み・公開待ち
  ↓ 予約日時に自動処理
公開済み
```

状態を前へ戻す画面機能はありません。

## 4. 下書き作成の入力

| 項目 | 条件 |
|---|---|
| 対象月 | 必須、`YYYY-MM`形式 |
| 名称 | 必須、255文字以内 |
| 明細項目設定 | 必須、自社の現在使用中設定だけ |

現在使用中の設定がない場合、作成フォームではなく設定作成への案内を表示します。

## 5. 保存処理

1. 選択設定が自社の使用中設定か再確認します。
2. 対象月をその月の1日の日付へ変換します。
3. ログイン中社員管理者を作成者として記録します。
4. 状態を「下書き」にして給与処理を保存します。
5. 詳細画面へ移動し、CSV取込を案内します。

作成直後は社員別明細が0件です。

## 6. 他社データの保護

一覧は自社の会社番号で絞ります。詳細を開く際も対象給与処理の会社番号を確認し、他社なら`404`です。

## 7. 注意事項

- 同じ対象月・同じ名称の給与処理を複数作成できます。
- 下書きの名称、対象月、設定を後から編集する画面はありません。
- 誤って作った下書きを削除する画面もありません。
- 使用中設定を後から停止・編集しても、給与処理本体は残ります。
- 作成者が削除されても給与処理は残り、作成者参照だけが空になります。

## 8. 動作確認の観点

1. 自社の使用中設定だけを選べること。
2. 作成時の状態が下書きであること。
3. 他社設定を送信値に指定しても拒否されること。
4. 状態別の件数と日時が一覧に正しく表示されること。
