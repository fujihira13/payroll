# 社員一覧・検索 — 処理概要

## 1. 目的

自社の一般社員と社員管理者を同じ社員台帳で確認し、編集、パスワード再発行、メール送信などの各操作へ進む機能です。

## 2. 一覧表示

`/company/employees`に社員番号順で20件ずつ表示します。

| 表示項目 | 内容 |
|---|---|
| 部署 | 現在の所属部署。未所属なら「未設定」 |
| 社員番号 | 自社内の社員識別番号 |
| ログインID | 共通ログインで使用するID |
| 社員名・メール | 本人情報とメール送信先 |
| ロック | ロック中か |
| 管理者権限 | 1：一般社員、9：社員管理者 |

利用停止状態を示す専用列は現在ありません。利用停止中の社員も、削除されていなければ一覧に表示されます。

## 3. 検索

1つの検索欄で次のいずれかに部分一致する社員を絞り込みます。

- 氏名
- 社員番号
- ログインID
- メールアドレス

検索条件はページ移動後も保持します。必ずログイン中の会社番号を条件に含めるため、他社社員は検索結果に出ません。

## 4. 同時に取得するメールテンプレート

一覧画面には社員ごとの「メール送信」操作があるため、自社の利用中メールテンプレートも名称順で取得します。

利用中テンプレートが1件もない場合、メール送信欄自体を表示しません。

## 5. 一覧から使える操作

- 社員登録画面を開く
- CSV見本ダウンロード、CSV取込
- 有効なテンプレートを選んで個別メール送信
- 社員編集
- パスワード再発行
- ロック中の場合のロック解除
- 削除または利用停止

## 6. データへの影響

一覧表示と検索だけではデータを更新しません。

## 7. 注意事項

- 削除済み社員は表示しません。
- 利用停止中を一覧で明確に判別できないため、編集画面を開いて「ログインを許可する」を確認する必要があります。
- 最終ログイン日時、ログイン失敗回数、初回パスワード変更状態は一覧に表示しません。
- 自分自身も社員一覧に表示されます。

## 8. 主な根拠ファイル

- `app/Http/Controllers/Company/EmployeeController.php`
- `resources/views/company/employees/index.blade.php`
- `app/Models/User.php`
