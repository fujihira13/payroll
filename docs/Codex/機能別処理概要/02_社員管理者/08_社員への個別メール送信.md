# 社員への個別メール送信 — 処理概要

## 1. 目的

社員一覧から1人を選び、事前に登録したメールテンプレートを使って個別連絡を送信する機能です。

## 2. 画面操作

1. 社員一覧を開きます。
2. 対象社員の行で使用するテンプレートを選びます。
3. 「メール送信」を押します。

自社に使用中テンプレートがない場合、送信操作は表示されません。

## 3. 送信前の確認

- 対象社員が自社所属か
- 選択したテンプレートが自社のものか
- テンプレートが使用中か

用途は確認しません。明細公開用・社員連絡用のどちらも、使用中なら選択できます。

## 4. 差込処理

社員と会社の情報を使い、件名と本文の差込文字を置き換えます。

| 差込文字 | 個別メールでの値 |
|---|---|
| `{company_name}` | 所属会社名 |
| `{department_name}` | 部署名、未所属なら空 |
| `{employee_name}` | 社員名 |
| `{login_id}` | ログインID |
| `{login_url}` | 共通ログインURL |
| `{payslip_title}` | 空文字 |
| `{payment_date}` | 空文字 |

テンプレートに送信者アドレスがあれば、そのアドレスと送信者名をFromに設定します。なければシステム既定を使用します。

## 5. 送信処理

メールは画面処理内で同期送信します。メールサーバーから送信処理が返るまで画面は待ちます。成功すると「○○さんへメールを送信しました」と表示します。

## 6. 更新されるデータ

社員情報やテンプレートは更新しません。個別メールの送信日時や本文を記録する専用テーブルもありません。

## 7. 注意事項

- 利用停止中社員にも送信できます。
- メールアドレスが登録されていれば、ロック中社員にも送信できます。
- 送信失敗を画面用メッセージへ変換する処理がなく、例外によりエラー画面になる可能性があります。
- 再送防止、送信履歴、予約送信、一括送信機能はありません。
- 給与公開用テンプレートを選ぶと、給与固有の差込値は空になります。

## 8. 動作確認の観点

1. 自社の有効テンプレートだけ選べること。
2. 他社社員・他社テンプレートが拒否されること。
3. 社員名、会社名、ログインID等が置換されること。
4. From指定あり・なしの両方で送信できること。
5. メールサーバー障害時の画面動作を確認すること。
