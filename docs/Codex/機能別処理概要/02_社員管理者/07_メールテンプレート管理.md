# メールテンプレート管理 — 処理概要

## 1. 目的

給与明細公開通知や社員への個別連絡で使用する、件名・本文・送信者情報を自社ごとに管理する機能です。

## 2. 一覧

`/company/email-templates`に自社テンプレートを名称順で全件表示します。

| 表示項目 | 内容 |
|---|---|
| テンプレート名 | 自社内で識別する名称 |
| 用途 | 明細公開または社員連絡 |
| 送信者 | 指定名・アドレス、未指定ならシステム既定 |
| 件名 | 差込前の件名 |
| 状態 | 使用中または停止中 |

ページングと検索はありません。

## 3. 登録・編集項目

| 項目 | 条件 |
|---|---|
| テンプレート名 | 必須、100文字以内、自社内で重複不可 |
| 用途 | `payslip_published`または`employee_notice` |
| 送信者名 | 任意、100文字以内 |
| 送信者アドレス | 任意、メール形式、255文字以内 |
| 件名 | 必須、255文字以内 |
| 本文 | 必須、5000文字以内 |
| 使用する | 必須の真偽値 |

登録時の会社番号はログイン中利用者から設定します。編集・削除では自社テンプレートか確認し、他社なら`404`です。

## 4. 差込文字

件名や本文に次の文字を書くと、送信時に実際の値へ置き換えます。

| 差込文字 | 内容 |
|---|---|
| `{company_name}` | 会社名 |
| `{department_name}` | 部署名。未設定なら空 |
| `{employee_name}` | 社員名 |
| `{login_id}` | ログインID |
| `{login_url}` | 共通ログインURL |
| `{payslip_title}` | 給与処理名。個別連絡では空 |
| `{payment_date}` | 実装上は給与対象月。個別連絡では空 |
| `{target_month}` | 公開通知処理では対象月として使用可能。ただし画面の差込案内には表示されていない |

## 5. 削除

削除は物理削除です。使用中かどうか、過去に使ったかどうかの確認は行いません。削除後の給与公開では、他の有効テンプレートまたはシステム既定文面を使用します。

## 6. 給与公開時の選択

自社の「明細公開」用途かつ使用中のテンプレートを、登録IDが小さい順に1件選びます。複数登録できるため、意図したものが選ばれるよう不要なテンプレートを停止する必要があります。

## 7. 注意事項

- テンプレート名は重複不可ですが、同じ用途のテンプレートは複数作れます。
- 個別メール送信では用途を限定せず、使用中なら明細公開用も選択できます。
- 本文はHTML編集ではなく、改行を保った通常テキストとして表示します。
- 送信者アドレスはメールサーバー側の許可と一致しないと送信失敗する可能性があります。
- 削除の復元、送信テスト、プレビュー機能はありません。

## 8. 動作確認の観点

1. 他社テンプレートを表示・編集できないこと。
2. 自社内の同名テンプレートを拒否すること。
3. 差込文字が送信時に置き換わること。
4. 停止中テンプレートが個別送信の選択肢に出ないこと。
5. 公開用途が複数あると先に登録した有効テンプレートが選ばれること。
