# 給与CSV見本・取込・金額計算 — 処理概要

## 1. 目的

自社明細設定に合った給与CSVの見本を出力し、社員ごとの値を取り込んで給与明細と合計金額を作る機能です。給与計算そのものを行うのではなく、CSVに記載された値を明細化・集計します。

## 2. 見本CSV

ファイル名は対象月を含む`payroll-YYYY-MM-template.csv`です。UTF-8のBOM付きで出力します。

先頭列は必ず`employee_number`で、その後に自社設定の「使用中」項目コードを並び順どおりに出力します。

```csv
employee_number,basic_salary,income_tax
```

データ行の見本は出力しません。

## 3. アップロード条件

- CSVまたはテキストファイル
- 最大5MB
- 下書き状態の給与処理だけ
- データ行が1件以上
- `employee_number`と全使用中項目コードの列が存在

UTF-8、SJIS-win、CP932を判定し、UTF-8へ変換します。空行は無視します。

## 4. 行ごとの確認

1. 社員番号で自社の社員を検索します。
2. 見つからなければ行番号付きでエラーにします。
3. 必須項目が空欄でないか確認します。
4. 金額・数値項目が数値として解釈できるか確認します。
5. カンマを除き、金額・数値を数値へ変換します。
6. 表示用の項目情報と値を明細用配列にまとめます。
7. 支給・控除の合計を計算します。

数値の`1,234`はカンマを除いて1234として扱います。空欄の任意数値は0です。

## 5. 金額計算

```text
総支給額 = data_type=amount かつ category=earning の合計
控除合計 = data_type=amount かつ category=deduction の合計
差引支給額 = 総支給額 - 控除合計
```

`number`は数値でも合計に含めません。`information`分類の金額も合計に含めません。

## 6. 明細へ保存する項目

各CSV値だけでなく、取込時点の次の情報も保存します。

- 項目コード
- 表示名
- 分類
- 種類
- スロット
- 値

これにより、後で自社設定を変更しても取込済み明細の表示項目は変わりません。

## 7. 新規作成と再取込

同じ給与処理・同じ社員の組み合わせは1件だけです。

- 初回取込：明細を新規作成
- 再取込：既存明細の項目と金額を上書き

全行を検査して準備した後、トランザクションで保存します。検査中に1行でもエラーがあれば1件も保存しません。

## 8. 現時点での注意事項

- 利用停止中社員も社員番号が見つかれば明細を作成できます。
- 社員管理者もroleがemployeeなので明細対象にできます。
- CSV内に同じ社員番号が複数行ある場合、最後の行で上書きされますが、成功件数はCSV行数として表示します。
- 余分な列は無視します。
- 負の金額、極端に大きい値、小数を禁止する業務ルールはありません。DBの14桁・小数2桁制約を超えると保存エラーになる可能性があります。
- 見本ダウンロード自体は状態制限がなく、公開済み処理でもURLから取得できます。
- 承認後はCSV取込を拒否します。

## 9. 動作確認の観点

1. 自社設定の使用中コードが見本列になること。
2. 必須列・必須値不足が行番号付きで拒否されること。
3. 支給・控除・差引が正しく計算されること。
4. 再取込で同じ社員の明細が増えず更新されること。
5. 1行エラーで全行保存されないこと。
6. 承認後の取込が拒否されること。
