# 自社明細設定一覧 — 処理概要

## 1. 目的

システム管理者が用意したベース帳票から、自社が作成した給与明細設定を確認する機能です。給与CSVの列と明細画面の表示内容は、この自社設定を基準にします。

## 2. 一覧表示

`/company/settings`に自社の設定を新しい順で全件表示します。

各設定には次を表示します。

| 表示 | 内容 |
|---|---|
| 設定名 | 自社内で付けた帳票名 |
| 元のひな型 | コピー元のベース帳票名 |
| 項目数 | 使用中に設定された項目数だけを数える |
| 状態 | 現在使用中または停止中 |
| 項目を編集 | 自社用項目の編集画面への入口 |

## 3. 取得処理

ログイン中社員管理者の`company_id`で自社設定だけを検索し、コピー元テンプレートと項目を同時に読み込みます。

会社設定には削除機能がありません。そのため、過去に作成した停止中設定も一覧に残ります。

## 4. 「現在使用中」の意味

給与処理の下書きを新規作成するときに選べるのは、使用中の設定だけです。

新しい自社設定を作成すると、同じ会社の既存設定はすべて停止中になります。編集画面で別設定を使用中へ切り替えた場合も、他設定を停止します。

## 5. データへの影響

一覧を見るだけではデータを更新しません。

## 6. 注意事項

- ページングと検索はありません。
- 設定名の重複は禁止されていません。
- 停止中設定でも編集できます。
- 停止中設定を使ってすでに作った給与処理は残ります。
- コピー元ベース帳票は、会社設定が存在する限り削除できない設計です。

- `resources/views/company/settings/index.blade.php`
