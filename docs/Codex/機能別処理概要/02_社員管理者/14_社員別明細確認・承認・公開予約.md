# 社員別明細確認・承認・公開予約 — 処理概要

## 1. 目的

CSVから作成された社員別給与明細を社員管理者が確認し、内容を確定して公開日時を予約する機能です。

## 2. 社員別明細の確認

給与処理詳細には、社員番号、氏名、部署、総支給、控除、差引支給、閲覧状況を表示します。「明細を見る」で社員ごとの内訳を確認できます。

社員管理者用の明細詳細は、給与処理が下書き・公開待ち・公開済みのどの状態でも閲覧できます。本人閲覧とは異なり、閲覧回数を増やしません。

対象明細が指定給与処理に属するかを確認し、組み合わせが違えば`404`です。給与処理自体も自社か確認します。

## 3. 承認前の条件

| 条件 | 内容 |
|---|---|
| 給与処理状態 | 下書きであること。違う場合は`422` |
| 明細件数 | 1件以上必要 |
| 公開予約日時 | 必須、現在日時以降 |

画面では承認ボタンを押すと「内容を確定し、公開予約しますか？」と確認します。

## 4. 承認処理

条件を満たすと次を更新します。

| データ | 更新値 |
|---|---|
| 状態 | 承認済み・公開待ち |
| 公開予約日時 | 入力日時 |
| 承認者 | ログイン中社員管理者 |
| 承認日時 | 現在日時 |

完了後は「指定日時に公開・通知されます」と表示します。

## 5. 承認後の制限

画面からCSV取込と承認フォームが消えます。サービス側でも下書き以外のCSV取込を拒否し、再承認は`422`です。

## 6. 状態別表示

| 状態 | 画面内容 |
|---|---|
| 下書き | CSV取込、承認フォーム、社員別明細 |
| 公開待ち | 公開予定日時、社員別明細 |
| 公開済み | 公開日時、通知成功件数、社員別明細 |

## 7. 現時点での注意事項

- 承認取消、公開日時変更、下書きへの差し戻し機能はありません。
- 承認時に全社員が含まれているか、重複月がないか、合計金額が妥当かを自動確認しません。
- 承認者本人の追加パスワード確認や二重承認はありません。
- 予約時刻を現在ちょうどにすると、次回の毎分実行で公開されます。
- 表示上は「承認後は明細内容を変更できません」で、サービス側でもCSV再取込を拒否します。

## 8. 動作確認の観点

1. 明細0件では承認できないこと。
2. 過去日時を指定できないこと。
3. 承認者・承認日時・予約日時が保存されること。
4. 承認後にCSV取込・再承認できないこと。
5. 社員管理者の明細確認で閲覧回数が増えないこと。
6. 他社給与処理・別処理の明細を指定できないこと。
