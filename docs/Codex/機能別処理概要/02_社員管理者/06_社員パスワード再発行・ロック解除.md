# 社員パスワード再発行・ロック解除 — 処理概要

## 1. 目的

社員がパスワードを忘れた場合に仮パスワードを発行したり、現在のパスワードを変えずにログインロックだけ解除したりする機能です。

## 2. 対象の保護

操作前に、対象社員がログイン中社員管理者と同じ会社かを確認します。他社社員なら`404`として処理しません。

## 3. パスワード再発行

1. 記号なし12文字の仮パスワードを生成します。
2. 対象社員のパスワードを更新します。
3. 初回パスワード変更を必要にします。
4. ロックを解除します。
5. 失敗回数を0に戻します。
6. 仮パスワードを画面に1回だけ表示します。

システム管理者向け再発行と異なり、社員の`is_active`は変更しません。利用停止中の社員へ再発行しても、利用停止のままです。

## 4. ロック解除

ロック中社員の「ロック解除」を実行すると、ロック状態を解除し失敗回数を0にします。パスワード、初回変更、利用可否は変えません。

## 5. 操作の比較

| 内容 | 再発行 | ロック解除 |
|---|:---:|:---:|
| パスワード変更 | する | しない |
| 仮パスワード表示 | する | しない |
| 初回変更必要 | する | 変更しない |
| ロック解除 | する | する |
| 失敗回数0 | する | する |
| 利用停止解除 | しない | しない |

## 6. 注意事項

- 仮パスワードは自動メール送信されません。安全な方法で本人に伝えます。
- パスワード再発行は確認ダイアログなしで直ちに実行されます。
- 社員管理者は自分自身のパスワードも再発行できます。
- 再発行しても現在のセッションを強制終了しません。
- 操作の監査ログはありません。

## 7. 動作確認の観点

1. 仮パスワードが12文字で1回だけ表示されること。
2. 旧パスワードが使えなくなること。
3. 初回変更画面へ案内されること。
4. 利用停止中社員は再発行後も利用停止であること。
5. 他社社員を操作できないこと。
