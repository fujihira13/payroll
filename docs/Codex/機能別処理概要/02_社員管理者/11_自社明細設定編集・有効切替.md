# 自社明細設定編集・有効切替 — 処理概要

## 1. 目的

コピー済みの自社明細設定を、会社の給与CSV・帳票運用に合わせて調整する機能です。項目の追加、削除、名称変更、分類変更、表示位置、必須・使用可否を変更できます。

## 2. 編集できる内容

| 内容 | 条件・影響 |
|---|---|
| 設定名 | 必須、255文字以内 |
| 現在使用中 | 有効にすると他の自社設定を停止 |
| 項目コード | 必須、60文字以内、設定内重複不可。給与CSV列名になる |
| 表示名 | 必須、255文字以内 |
| 分類 | 支給、控除、勤怠・その他 |
| 種類 | 金額、数値、文字 |
| スロット | レイアウト内の位置、または未割当 |
| 使用 | 給与CSV・明細へ含めるか |
| 必須 | CSVで空欄を許可するか |

レイアウト自体は画面上で読み取り専用です。項目は追加でき、不要な行を画面から削除できます。

## 3. 他社データの保護

編集対象設定の会社番号とログイン中の会社番号を比較します。他社設定なら`404`です。

## 4. 保存処理

1. 設定と全項目を検査します。
2. トランザクションを開始します。
3. この設定を使用中にする場合、他の自社設定を停止します。
4. 設定名、状態、最終設定者を更新します。
5. 現在の自社項目をすべて削除します。
6. 画面の項目を新しい並び順で作り直します。
7. 全て成功した場合だけ確定します。

項目の内部IDは保存のたびに変わります。

## 5. 給与処理への影響

給与明細へCSVを取り込んだ時点で、表示用の項目名・分類・種類・スロット・値を明細内へ保存します。そのため、取込済みの過去明細は設定編集で変わりません。

ただし、下書き給与処理が参照する設定項目は取込時点の最新設定です。下書き作成後、CSV取込前または再取込前に設定を編集すると、見本CSVの列や検査条件が変わります。

## 6. 有効切替

- 有効にすると他の自社設定をすべて無効化します。
- 無効にする場合、代わりの設定を自動で有効にはしません。
- 全設定が無効になると、新しい給与処理を作成できません。
- 既存の給与処理は設定が無効になっても残ります。

## 7. 注意事項

- スロット重複は許されます。
- 1件でもスロット付き項目があると明細はスロット表示になり、未割当項目が表示されない可能性があります。
- 使用中項目を0件にできます。
- 給与処理で使用中の設定でも編集を禁止していません。
- 設定削除機能はありません。
- コピー元のベース帳票が停止していても、既存の自社設定は編集できます。

## 8. 動作確認の観点

1. 他社設定を編集できないこと。
2. 項目追加・削除・順序・スロットが保存されること。
3. 有効化で他設定が停止すること。
4. 取込済み過去明細が変化しないこと。
5. 下書き中の見本CSVが設定編集で変わることを確認すること。
