# 給与明細ポータル テスト仕様書

文書版: 1.1
作成日: 2026-08-25  
対象環境: Docker Composeローカル学習環境

## 1. 目的

`/manage`のシステム管理者、`/login`のpermission 1（一般社員）・9（社員管理者）、会社間分離、給与明細の作成から公開・通知・閲覧までが仕様どおり動作し、異常入力や権限外アクセスでデータを漏えい・破損しないことを確認します。

## 2. 対象と対象外

対象:

- Docker起動、ヘルスチェック、データ保持
- 認証、ログアウト、権限、会社・本人分離
- 会社、permission 1・9の社員、部署、共通テンプレート、自社設定
- 社員CSV、給与CSV
- 給与処理、承認、予約公開、通知メール
- 社員の明細閲覧、PDF、パスワード変更、閲覧記録
- PC・スマートフォン表示、代表ブラウザ

対象外:

- 本番負荷試験、耐障害・災害復旧試験
- 第三者による脆弱性診断、侵入試験
- 外部メールサービス、給与・勤怠・会計システム連携
- 法務・労務上の給与明細記載要件の適合性

## 3. テスト環境と基準データ

| 項目 | 内容 |
|---|---|
| URL | `http://localhost:8080` |
| メール確認 | `http://localhost:8025` |
| DB | 通常確認は`payroll`、自動テストは`payroll_test` |
| ブラウザ | Chrome最新版相当を主対象、Edge最新版相当を互換確認 |
| 画面幅 | PC 1440px、スマートフォン 390pxを代表値 |
| 会社 | A社、B社 |
| 利用者 | システム管理者、A社管理者、B社管理者、A社社員A001/A002、B社社員B001 |
| 部署 | A社: SALES/GENERAL、B社: SALES |
| 明細項目 | 基本給・時間外手当・交通費・健康保険・厚生年金・所得税・備考 |

判定基準:

- 期待結果をすべて満たせば合格です。
- HTTPステータス、DB反映、メール、ダウンロード内容を必要に応じて併せて確認します。
- 個別ケースで指定がない限り、Laravelログに未処理例外が出ないことを確認します。
- テストで発見した不具合修正後は、該当ケースと関連する自動テストを再実施します。
