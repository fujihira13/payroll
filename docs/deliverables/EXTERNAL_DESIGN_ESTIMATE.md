## 2. 前提

- 現行の学習用実装を設計根拠とする。
- 対象は3権限、約21画面相当、2種類のCSV、通知メール、PDF、ヘルスチェック、予約公開処理とする。
- 成果物はMarkdownとし、顧客固有のWord・Excel様式への転記は含めない。
- 打合せは2回、各1時間までを含む。
- レビュー指摘は軽微な修正を1回含む。
- 日本語1言語、PCとスマートフォンのレスポンシブ画面を対象とする。

## 3. 含まない作業

- 要件の大幅な再定義、法務・労務判断
- 本番インフラ、バックアップ、監視、災害復旧の詳細設計
- 画面モックの新規デザイン制作、Figma成果物
- API詳細設計、外部給与システムとの連携設計
- データ移行設計、性能試験設計、脆弱性診断仕様
- 実装変更、テスト実施、操作マニュアルの利用者教育

## 4. 変動要因

現時点の精度は概算で、目安は`7.5人日 ±25%`です。会社ごとの承認フロー、法定帳票、監査ログ、外部メール、パスワード再設定、多要素認証、バックアップ・復元を追加すると再見積が必要です。
